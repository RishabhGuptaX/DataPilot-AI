# DataPilot AI

AI-Powered Data Analysis & Cleaning Copilot.

## Planned Features

- CSV and Excel ingestion
- Automated dataset profiling
- AI-assisted data cleaning
- Natural-language data analysis
- Automated EDA and insights
- Interactive Plotly visualizations
- Downloadable analysis reports

## Tech Stack

Python, Streamlit, Groq, Pandas, NumPy, Scikit-learn, Plotly

## Development

This project is being built incrementally. The initial repository contains the planned production-oriented structure; implementation will be added phase by phase.
